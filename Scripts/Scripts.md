# Scripts

| Script | Path | Usage |
|---|---|---|
| Dev build | `Scripts\dev_build.py` | Publishes Agent, CLI, MCP, Worker and UI into the install layout (`artifacts\dev` by default; worker and UI in subfolders). `python Scripts/dev_build.py [--test] [--only Agent,UI] [--out DIR]`. Adds the VS Installer folder to PATH so Native AOT linking finds vswhere. |
| Single-file package (local only, not in the public repo yet) | `Scripts\package_single.py` | Builds the install layout into `artifacts\release\BetterRecall-<ver>-win-x64`, adds licence files, zips it and appends it with a hash trailer to the Native AOT launcher, giving `artifacts\release\BetterRecall-<ver>-win-x64.exe`. `python Scripts/package_single.py [--test] [--skip-build] [--copy-to DIR]`. Version comes from `Directory.Build.props`; models are not included. |
| README images | `Scripts\readme_images.py` | Screenshots of the real UI in mock mode (demo data) plus the banner, into `docs\images`. `python Scripts/readme_images.py [--exe PATH] [--out DIR] [--only search,home,timeline,light,banner]`. Crops each window to its visible frame (no black resize-border bars); needs pillow and uiautomation. |
| Model pipeline | `Scripts\models\prepare_all.py` | One command for venvs, pinned downloads, all exports, the OpenVINO GenAI runtime and a worker rebuild. `python Scripts/models/prepare_all.py [--skip-venv] [--only embeddinggemma2,whisper]`. Venvs in `%BETTERRECALL_DEV%` (default `%LOCALAPPDATA%\BetterRecall-dev`), models and HF cache in `%LOCALAPPDATA%\BetterRecall`. |
| Model fetch | `Scripts\models\fetch_models.py` | Downloads the pinned official files (all, or names given) into the Hugging Face cache; Silero VAD straight into the models folder. Run in the main venv. |
| EmbeddingGemma 2 export | `Scripts\models\export_embeddinggemma2.py` | Text graph, vision graphs at 70/140/280 tokens and bf16 token table, with cosine, NaN, compile-time and latency checks on CPU and NPU. `--random-init --config-dir DIR --no-save` checks the architecture without weights. |
| SigLIP 2 export | `Scripts\models\export_siglip2.py` | Static-shape image and text towers for the NPU fallback, with cosine checks. |
| ONNX export | `Scripts\models\export_onnx.py` | Adds float32 ONNX twins of the EmbeddingGemma 2 and SigLIP 2 graphs (EmbeddingGemma 2: dynamic-length text, one vision graph for every token budget) and an `onnx` map to each manifest, so DirectML graphics cards can run search; checks ONNX Runtime CPU against PyTorch (cosine >= 0.9999). `python Scripts/models/export_onnx.py [--out STAGING] [--affinity 0x3fc3c]` in the main venv, after the IR exports. |
| Whisper export | `Scripts\models\export_whisper.py` | INT8 OpenVINO export for GenAI WhisperPipeline (whisper venv). `--tts out.wav` reports compile time and real-time factor on NPU and CPU. |
| NSFW export | `Scripts\models\export_nsfw.py` | ViT classifier to ONNX: `model_int8.onnx` (dynamic INT8, per-channel weights, no calibration data) for the CPU and `model_fp32.onnx` (manifest `acceleratorFile`) for NPU and GPUs, plus an FP32 vs INT8 agreement report. Static calibrated INT8 drifted up to 0.16 on real screenshots; dynamic stays within 0.03. Main venv. |
| NSFW detector export | `Scripts\models\export_nsfw_detector.py` | Copies NudeNet `320n.onnx` (deepghs/nudenet_onnx, pinned revision, size and SHA-256 checked) to `models\nsfw-detector\model.onnx` and writes the manifest `detector` section (640 px, 18 labels, 9 block labels). `--from FILE` uses a local copy instead of the Hugging Face cache. Main venv. |
| NSFW check | `Scripts\models\nsfw_check.py` | Scores real images with the FP32 PyTorch reference and the installed INT8 model, using the manifest preprocessing. `python Scripts/models/nsfw_check.py [--threshold 0.8] [--csv out.csv] DIR...`. Put safe and NSFW samples in separate folders to read false positives and misses. Main venv. |
| GenAI runtime | `Scripts\models\stage_genai_runtime.py` | Downloads and sha256-checks the OpenVINO GenAI archive, stages `openvino_genai_c.dll` and tokenizer DLLs into `artifacts\native\openvino-genai\` for the worker build. |
| Shared helpers | `Scripts\models\common.py` | Pinned sources, paths, manifest writer, cosine check. Imported by the others. |
| Retrieval test | `Scripts\retrieval\` | Checks real-model search quality. `render.py <dir>` draws 10 screens of known content plus 20 multilingual queries and 3 off-topic ones; `agent\` is a harness named `BetterRecall.Agent.exe` that drives the real worker (publish it to an install dir with `worker\` copied from `artifacts\dev`); `run.sh <tokens>` embeds everything; `score.py set.json out.json` prints R@1, MRR and cosine bands; `reference.py` computes the PyTorch reference for comparison. |
| Codec DLLs | `Scripts\build_codecs.sh` | Rebuilds `avif.dll` and `jxl*.dll` for the agent with vcpkg at a pinned commit (custom triplet: static deps and CRT, release only) into `K:\cache\br-codecs`. `bash Scripts/build_codecs.sh`, then copy the four DLLs to `src\BetterRecall.Agent\Native\`. Re-check the struct offsets in `Avif.cs` / `Jxl.cs` after a port bump. |
