Chapter 3

Local-First Semantic Retrieval on Edge NPUs

Continuous desktop indexing presents a sharp trade-off between recall accuracy, power draw, and user privacy. Offloading screen captures to remote inference clusters introduces unacceptable confidentiality risks for personal documents, financial records, and private correspondence. In this chapter we evaluate a fully local hybrid retrieval pipeline combining quantized multimodal embeddings with lexical full-text search.

3.1 Hybrid Index Architecture

Each captured frame is processed asynchronously by an isolated worker process. Text extracted via on-device OCR is tokenized into an encrypted FTS5 index, while dense visual embeddings are compressed to int8 vectors and scored via reciprocal rank fusion (RRF) at query time.

score(d, q) = w_lex · BM25(d, q) + w_vec · cos(e_d, e_q)

3.2 Evaluation Methodology

We measure Recall@1, Mean Reciprocal Rank (MRR), and median query latency across a multilingual corpus of desktop captures spanning code editors, spreadsheets, technical documentation, and messaging threads.
