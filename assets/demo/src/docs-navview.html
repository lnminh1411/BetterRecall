NavigationView Class

Namespace: UI.Xaml.Controls  •  Assembly: WinUI.Controls.dll

Represents a container that enables navigation of app content. It has a header, a view for the main content, and a menu pane for navigation commands that adapts across compact, minimal, and expanded window widths.

public class NavigationView : ContentControl
